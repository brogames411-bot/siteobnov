# Сайт «Рядом»

Статический многостраничный сайт на HTML, CSS и JavaScript. Запускается без установки зависимостей: откройте `index.html` в браузере или разместите всю папку `site` на статическом хостинге.

## Страницы

- `index.html` — главная
- `services.html` — услуги
- `prices.html` — цены
- `about.html` — о нас
- `contacts.html` — адрес и панорама

## Что настроить перед публикацией

1. В `assets/config.js` уже указан Telegram username `prx_001`. Кнопка откроет переписку с этим аккаунтом и подставит сообщение. Чтобы сменить получателя, укажите другой username без `@`.
2. В `assets/config.js` при необходимости измените текст записи. Сейчас он установлен точно как в запросе: `здравстуйте, хочу записаться`.
3. Замените универсальные примеры услуг на реальные названия, описания, цены и данные бизнеса. Они находятся в `services.html`, `prices.html`, `about.html` и на главной странице.
4. В `contacts.html` встроена панорама Яндекс Карт по координатам адреса Пороховая, 55. Ссылка под панорамой открывает её в Яндекс Картах отдельно.
